Q2 · why it has to be built for Pakistan

Design choices you can see on screen.

Paper first

Classes run on paper. EDUOS reads handwritten sheets from a phone photo — students need no device at all.

Urdu, the way we teach

Qwen-MT translates to Urdu while a glossary keeps Python · set · loop in English.

آپ کا سب سے کمزور تصور Python میں loops ہے۔

Low bandwidth, low cost

Photos shrink on the phone before upload. Marking one answer sheet costs about Rs 0.23, measured.

Measured on Alibaba Model Studio (Singapore), qwen3-vl-plus, 1,696 tokens per sheetP00733
Q5 · what the AI does, and why it's needed

Three Qwen models, each doing work rules can't.

Model (Model Studio)JobGuardrail
qwen3-vl-plusReads handwriting, marks each answer against the key with a reasonTrainer confirms every mark; handwriting is treated as data, never instructions
qwen-plusTargeted practice · adaptive viva · gig proposal · copilot · command centerNumbers checked by the grounding guard; tool calls over a 17-tool allowlist, no NL→SQL
qwen-mt-flashUrdu explanations with an English technical glossaryTranslation runs after the guard, so meaning is checked first

If the model is down, every screen completes on a labelled computed fallback — and a viva can never be "Verified" without Qwen.
